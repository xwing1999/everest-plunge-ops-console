Start a New Batch (or add to one)

Creates "Batch N - In Production" (ordered from the factory) or "Batch N - On Water" (already shipped), one row per unit. Waiting customers in Next Custom Order can be moved straight onto the new units. Running it again for the same batch adds more units. Rename a batch from its tab at the top of the page.

Batch Shipped

Use when a batch leaves the factory. Renames "Batch N - In Production" to "Batch N - On Water" — every unit and every customer on it stays exactly as is — and flips those orders to On Water.

Batch Arrived

Use when a batch lands in the warehouse. Moves every unit on "Batch N - On Water" (allocated and free) into Stock On Shore with its customer attached, removes the emptied batch tab, and flips those orders to "Ready to organise". The manual Stock Overview tab in the sheet isn't changed — update its counts separately if you still use it.

Products To Order

Every "Next Custom Order" deal not yet in production, grouped by SKU — the live shopping list for the next China order. When the order is placed, use Start Production Batch above: it moves these customers onto the new batch's units. The "Stock shortfall" column comes from the manual Stock Overview tab — verify before ordering.
